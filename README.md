Aplicação web desenvolvida como projeto acadêmico para facilitar o compartilhamento de informações sobre unidades de saúde do SUS, permitindo consultar dados como disponibilidade de medicamentos, horários de atendimento, agendamentos e funcionamento das unidades.

Tecnologias utilizadas: HTML5, CSS3, JavaScript, Node.js, Express.js, MySQL e Fetch API.
